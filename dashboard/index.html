How the ranking works

1 · Find the protocols that record no token

Every protocol in the sealed snapshot is checked. A protocol counts as pre-token only if it records no token — no market cap, no CoinGecko id, no symbol — and is not a wrapped, staked or bridged product of a token that trades, not an exchange, and not a versioned pool. The snapshot's 40-protocol watchlist is the floor; the board adds every rankable protocol below it.

2 · Price the launch from the market's own comps

Implied value = TVL × category multiple × 2.0 × P(launch) × growth × maturity. The multiple is the median market-cap / TVL of the snapshot's own live-token protocols in the same category (categories with fewer than 3 comps use the global median). The 2.0× is the FDV uplift: a launch's fully-diluted value runs about twice its circulating market cap.

3 · Weight by launch probability

P(launch) runs 0.30–0.85 by category. Retail protocols — prediction markets, DEXes, lending — are far more likely to launch a token than institutional vault curators, so each category carries its own probability. The board ranks by implied value — the honest answer to “what is this launch worth?”

4 · Score farmability

Each protocol gets a 0–100 farmability score: how easy and cheap it is for a real user to farm (chain count, growth, category). The farm steps in the detail panel are the standard on-chain actions for that category, customised with the protocol's own chains and TVL.
